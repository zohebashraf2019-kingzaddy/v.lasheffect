## Included
- `index.html`
- `assets/` with logo, owner photo, work images, policies, and payment graphic

## Deploy with GitHub + Vercel
1. Unzip the folder.
2. Create a new GitHub repository.
3. Upload `index.html`, `README.md`, and the entire `assets` folder.
4. In Vercel select **Add New > Project**.
5. Import the GitHub repository.
6. Framework preset: **Other**.
7. Leave the build command blank.
8. Leave the output directory blank.
9. Deploy.
